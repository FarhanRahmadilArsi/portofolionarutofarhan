Segmentasi Nasabah & Deteksi Pola Transaksi Perbankan

Unsupervised Learning · K-Means Supervised Learning · Decision Tree & Random Forest Python

Project ini mengombinasikan Unsupervised Learning (K-Means) untuk menyegmentasikan ±2.500 data transaksi perbankan dan Supervised Learning (Decision Tree & Random Forest) untuk melatih model klasifikasi berdasarkan segmen tersebut, dengan fokus utama menerjemahkan hasil pemodelan menjadi insight bisnis yang bernilai. Submission ini dikerjakan sebagai bagian dari program Belajar Machine Learning Pemula (BMLP).
